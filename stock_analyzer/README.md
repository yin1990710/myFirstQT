# 个股多维度分析程序

给定一个 A 股代码，自动输出「基本面 / 技术面 / 行业板块资金 / 同板块龙头 / 消息面与近期大事」五维分析，并汇成 0-100 综合评分与操作策略。输出控制台报告、Markdown 和单文件 HTML（内含自绘走势图，无需联网渲染）。

```
python analyze.py 688213
```

---

## 一、快速开始

```bash
cd stock_analyzer
pip install -r requirements.txt          # akshare / pandas / numpy / requests

python analyze.py 688213                 # 完整报告：控制台 + Markdown + HTML
python analyze.py 600707 --industry 光学光电子   # 手动指定板块，跳过行业识别
python analyze.py 002129 --no-html       # 只要控制台 + Markdown
python analyze.py 300750 --json          # 额外导出结构化 JSON
python analyze.py 688213 --no-cache      # 忽略缓存，强制重新抓取
```

| 参数 | 说明 |
|---|---|
| `code` | 6 位股票代码（必填） |
| `--industry` | 手动指定同花顺行业板块名，覆盖自动识别 |
| `--out` | 输出目录，默认 `output/` |
| `--no-html` / `--no-md` | 跳过对应格式 |
| `--json` | 额外输出 JSON 摘要（供二次开发） |
| `--no-cache` | 清空缓存后重跑 |
| `--quiet` | 只写文件，不打印控制台报告 |
| `--days` | 日线回溯天数，默认 420 |

首次运行约 30-60 秒（全市场个股资金流约 20 秒），之后命中缓存约 1 秒。

## 二、五个维度分别怎么算

### 1. 基本面（25 分）

| 子项 | 分值 | 指标 |
|---|---|---|
| 成长性 | 8 | 营业总收入同比、归母净利润同比（按档位给分，净利同比封顶 300%） |
| 盈利能力 | 7 | 毛利率、销售净利率、ROE（按报告期年化：Q1×4、H1×2、Q3×4/3） |
| 收益质量 | 5 | 经营现金流/净利润、应收账款周转天数、存货周转天数 |
| 财务健康 | 2 | 资产负债率（越低越高分） |
| 相对估值 | 3 | PE(TTM) 与板块成分股中位 PE 的比值 |

同时输出：公司画像、近 8 个报告期财务概览、主营构成（按产品/按地区，含毛利率）。

### 2. 技术面（30 分）

| 子项 | 分值 | 指标 |
|---|---|---|
| 趋势结构 | 8 | 均线多头排列（MA5>10>20>30）、价格站上 MA30/MA60、MA30 的 20 日斜率 |
| 动量 | 6 | 近 20 日涨幅、相对板块指数 20 日超额收益 |
| 摆荡指标 | 6 | MACD（DIF/DEA/柱）、RSI(14)、KDJ(9,3,3) |
| 量能 | 5 | 5日/20日均量比、量比、放量上涨/放量下跌区分 |
| 形态位置 | 5 | **W23 模型**（见下）、距 250 日收盘高/低点 |

额外输出：支撑/压力位（摆动点 + 近 20/60 日极值）、近 10 个交易日明细。

**W23 形态模型**（`analyzer/indicators.py::detect_w23`）是「波浪 + 5/30 均线 + 量能」的简化规则引擎，不是严格的艾略特计数：

1. 用 MA30 方向判定趋势（上行 / 下行 / 走平）；
2. 用局部极值法找已确认的摆动高低点，计算自最近高点的回撤幅度；
3. 回撤落在 12%~55%、缩量后重新站上 MA30 → 判为「浪2调整末 / 浪3启动」；
4. 均线多头但价格偏离 MA30 超过 25% → 判为「高位 / 浪5 风险区」；
5. 输出 `stage / stage_code / confidence / 回撤 / 摆动高低点 / 均线位置 / 量能`，阶段分（0-5）直接进入技术面加分。

### 3. 行业板块资金（15 分）

| 子项 | 分值 | 指标 |
|---|---|---|
| 行业资金流排名 | 5 | 该行业当日主力净额在 90 个行业中的分位，净流出倒扣 |
| 板块趋势强度 | 4 | 板块指数 5 日 / 20 日涨幅 |
| 资金强度 | 3 | 净额 / 流入总额 |
| 个股资金地位 | 3 | 个股主力净额在同一板块成分股中的排名分位 |

同时输出行业资金流排行（净流入 Top8 / 净流出 Top5）、板块领涨股、所属概念标签。

### 4. 同板块龙头（10 分）

| 子项 | 分值 | 指标 |
|---|---|---|
| 市值分位 | 4 | 流通市值在板块内的百分位 |
| 成交额分位 | 2 | 当日成交额在板块内的百分位 |
| 相对涨幅 | 2 | 当日涨幅 vs 板块中位数 |
| 与龙头差距 | 2 | 自身流通市值 / 板块龙头流通市值 |

同时输出板块市值前 10 梯队表（★ 标注当前标的）、今日涨幅前 5。

### 5. 消息面 / 近期大事（20 分）

| 子项 | 分值 | 指标 |
|---|---|---|
| 新闻情绪 | 8 | 正负向词典打分（先按公司名/代码筛相关新闻，不足 3 条时退回全量） |
| 公告事件 | 6 | 增减持、回购、股权激励、并购重组、重大合同、质押、解禁、监管问询等分类计分 |
| 卖方研报 | 4 | 近 180 天覆盖机构数、买入+增持占比、一致预期 EPS 增速 |
| 龙虎榜 | 2 | 近 90 日上榜次数与净买额 |
| 产品价格 | — | 有对应期货主力合约的直接取价格序列（20/60 日涨跌）；无则给出跟踪要点，明确标注"无公开连续报价源" |

## 三、评分与结论

- 五大维度按权重加权（25/30/15/10/20）。**某维度数据缺失时自动按剩余维度权重归一化**，不会把缺数据当成 0 分。
- 总分 → 评级：`A+ ≥80 / A ≥70 / B ≥60 / C ≥50 / D <50`。
- 操作建议由「总分 + W23 形态 + 正负信号共振度」共同决定，输出 `积极关注 / 逢回调关注 / 观察 / 回避减仓` 四档，并附风险等级、主要风险点与具体策略描述。

## 五、数据源与实测可用性

本项目对每个接口都做过真实调用验证（2026-10 实测）。**东方财富 `push2*` 系列域名在部分网络环境下会被阻断**（实时盘口、东财板块成分、东财个股资金流均走该域名），因此做了一套替代方案：

| 数据 | 实际使用 | 备注 |
|---|---|---|
| 实时行情 / PE / PB / 市值 / 量比 | 腾讯财经 `qt.gtimg.cn` | 批量 60 只/请求，单只也是 1 次请求 |
| 日线（前复权） | 新浪 `stock_zh_a_daily` → 腾讯 `web.ifzq.gtimg.cn` 兜底 | 含换手率（已换算为百分数） |
| 财务摘要 / 财务指标 | 新浪（akshare 封装） | 80+ 指标、多报告期 |
| 主营构成 / 主营介绍 | 东财 `datacenter-web` / 同花顺 F10 | 按产品与按地区，含毛利率 |
| 公司概况 / 行业三级分类 | 东财 `emweb` F10 | `EM2016`、证监会行业、员工数 |
| **个股所属板块反查** | 东财 `datacenter-web` `RPT_BOARD_CONSTITUENT` | 一次请求拿到行业/概念/地域/风格四类标签 |
| **板块完整成分股** | 同上，`BOARD_NAME` 过滤 | 一次请求取全（如半导体 188 只） |
| 行业与概念资金流 | 同花顺 `data.10jqka.com.cn` | 90 个行业即时净额 |
| 全市场个股资金流 | 同花顺（约 5200 行） | 约 20 秒，缓存 30 分钟 |
| 板块指数历史 | 同花顺 `stock_board_industry_index_ths` | 用于相对强度 |
| 新闻 | 东财搜索接口 | 30 条，按公司名/代码筛相关性 |
| 公告 | 东财 `np-anotice-stock` | 含公告类型标签，用于事件分类 |
| 研报评级 / 盈利预测 | 东财 `datacenter-web` | 含 3 年 EPS 预测与 PE |
| 龙虎榜 | 东财 `datacenter-web` | 按代码过滤近 90 日 |
| 产品价格代理 | 新浪期货主力连续 | 碳酸锂/多晶硅/玻璃/纯碱/铜铝等 |

**行业识别**为三层兜底，实测 6 个跨行业标的（半导体/面板/光伏/电池/银行/化工）全部命中：

1. 东财板块反查 `BOARD_TYPE_NEW=2` 的行业层级，与同花顺 90 个行业名求交集，多级命中取最细分的一级；
2. 东财 `EM2016` 三级行业字符串 + 人工别名表（`config.INDUSTRY_ALIAS`）+ 模糊匹配；
3. 兜底取最相似名称，并在报告中标注「未校验」。

## 六、稳健性设计

- **单模块失败不影响整份报告**：任一维度抛异常会被捕获，标记为「数据缺失」并剔除该维度权重，其余维度照常出结果。
- **网络双通道**：默认绕过系统代理直连（更快），失败自动回落系统代理，指数退避重试 3 次。
- **磁盘缓存**：行情 2 分钟、资金流 5 分钟、财务/行业 12 小时、公司概况 7 天，避免频繁打接口被限流。
- **数值解析不吞零**：`1.66亿` / `-6617.00万` / `12.73%` / `False` 统一解析，无法解析返回 `None` 而非 `0`，避免把"缺失"算成"业绩为零"。

## 七、如何改成你自己的模型

| 想改什么 | 改哪里 |
|---|---|
| 五维权重 | `analyzer/config.py::WEIGHTS` |
| 评级分档 | `analyzer/config.py::RATING_BANDS` |
| 各子项给分档位 | 对应模块里的 `band_score([...])` 列表，如 `fundamental.py` 的成长性档位 |
| 行业别名（识别错误时） | `analyzer/config.py::INDUSTRY_ALIAS`，或用 `--industry` 临时覆盖 |
| 情绪词典 | `analyzer/config.py::POSITIVE_WORDS / NEGATIVE_WORDS` |
| 公告事件分类 | `analyzer/config.py::ANNOUNCE_CATEGORIES` |
| 期货代理品种 | `analyzer/config.py::PRODUCT_FUTURES` |
| W23 参数（回撤区间、摆动窗口） | `analyzer/config.py::W23_*` |
| 新增一个维度 | 在 `modules/` 下仿照现有模块写 `analyze()` 返回 `ModuleResult`，在 `analyze.py` 的 `steps` 里登记，在 `WEIGHTS` 补权重 |

## 八、已知限制

1. 资金流为**同花顺即时口径**（当日主力净额），单位亿元；不同数据商的大单口径有差异，只适合做相对强弱比较，不宜跨源对照绝对值。
2. 新闻情绪是**词典法**，不做语义理解，遇到财经媒体的大盘综述类文章会有噪声（已通过"公司名/代码相关性"过滤缓解）。
3. 财务数据以最近一期报告为准，**不做单季度拆分**，同比为累计口径。
4. 「主要产品价格」多数行业没有公开连续报价，只能用期货代理或文字提示，**不等于公司实际售价**。
5. W23 是规则引擎，输出的是"形态标签"而非概率；`confidence` 为启发式分值，不可当胜率解读。
6. 程序输出为研究框架验证用途，**不构成投资建议**。

`output/688213_思特威-W_YYYYMMDD_HHMM.html`：

- 五维评分条形图
- 近 120 日走势（收盘价 + MA20/MA30 + 成交量，红涨绿跌）
