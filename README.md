# stock_analyzer —— 通用 A 股走势分析报告生成器

输入股票代码，自动拉取行情/技术/资金/筹码数据，输出结构化 HTML 分析研报。

## 快速开始

```bash
# 单只标的
python -m stock_analyzer 688213

# 指定输出文件
python -m stock_analyzer 688213.SH -o 思特威报告.html

# 多只批量，输出到指定目录
python -m stock_analyzer sh600519 sz300750 601318 -d reports/

# 只输出结构化结论（JSON，便于喂给其他程序）
python -m stock_analyzer 300750 --json

# 生成后自动打开浏览器
python -m stock_analyzer 002594 --open
```

## 代码格式

以下写法均可，程序会自动归一化：

| 输入 | 归一化结果 |
|---|---|
| `688213` / `600519` / `300750` | 按首位数字推断市场 |
| `688213.SH` / `000001.SZ` | 后缀形式 |
| `sh688213` / `SZ300750` | 前缀形式（大小写不敏感） |

## 依赖

- Python 3.10+
- `westock-data` CLI（WeStock 行情工具，需在 PATH 中）
- `node`（可选，用于 HTML 内联 JS 语法自检；缺失时自动跳过）
- 报告通过 CDN 加载 ECharts 渲染图表

## 分析框架

程序输出与 `workbuddy-finance-skill` 的方法论一致，共十一项：

1. **核心行情数据** — 收盘/振幅/量比/市值/估值/区间涨跌
2. **日K结构** — K 线图 + MA5/MA20/MA60
3. **量能分段统计** — 自动等分区间，标注放量/缩量
4. **技术指标全景** — MA/MACD/KDJ/RSI/BOLL/筹码
5. **资金面** — 主力/超大单/大单/中单/小单 + 融资融券
6. **关键价位地图** — 自动计算压力位/支撑位/斐波那契回撤
7. **基本面与估值** — 一致预期 + 评分体系
8. **多体系信号投票** — 11 个体系独立给票
9. **条件化情景框架** — 突破/假突破/结构破坏/资金验证
10. **近期研报与资讯**
11. **数据缺口说明** — 各数据源失败均显式披露

## 技术体系说明

| 体系 | 判定逻辑 |
|---|---|
| 均线系统 | 价格站上均线数量 + MA5>MA10>MA20 多头排列 |
| MACD | 12-26-9，零轴上下 + 金叉死叉 + 柱状 5 日变化 |
| KDJ | 9-3-3，J>90 判超买（优先于金叉），J<5 判超卖 |
| 成交量 | 对比 20 日均量，放量阈值 1.5 倍、缩量 0.7 倍 |
| K 线形态 | 12 种蜡烛图形态（锤子/倒锤/十字/纺锤/吞噬/孕线/晨星/暮星/红三兵/黑三鸦等） |
| 一目均衡表 | 9/26/52 周期云图，价格位于云上/云内/云下 |
| 价格结构 | 高点低点同步升降 → 上行/下行/震荡 |
| 形态识别 | 摆动高低点（窗口 3）自动识别 W 底、M 顶，标注抬升/下降变体 |
| 主力资金 | 单日净额与股价方向是否背离（阈值 0.3 亿）+ 5 日累计 |
| 融资余额 | 环比变动（阈值 2%）+ 当日净买入 |
| 筹码结构 | 获利盘 >80% 判偏空、<20% 判偏多 |
| 技术/成长评分 | 70 分以上偏强、50 分以下偏弱 |

**信号投票规则**：多空票数相差 1.8 倍以上才判定方向明确，否则标记为分歧，并把「资金背离」作为分歧核心输出。

## 已处理的数据坑

- **成交量单位不统一**：实测科创板（688）返回「股」，沪深主板/创业板返回「手」。程序用 `amount / (volume × price)` 反推自动归一化，不依赖板块硬规则。
- **单点失败降级**：任一数据源失败只记录到「数据缺口说明」，不中断整体流程；核心数据（行情/K线）失败才报错退出。
- **非交易日**：数据时点取接口返回的 `time` 字段，标注为该日收盘，不假设是今天。
- **JS 语法自检**：交付前抽取内联 `<script>` 执行 `node --check`，防止一处括号失配导致全页图表失效。

## 作为库调用

```python
import sys; sys.path.insert(0, '/path/to/stock_analyzer_parent')
from stock_analyzer import datasource as ds, engines as E, report as rp

code = ds.normalize_code("688213")
b = ds.load(code)                      # Bundle：全量数据
st = E.analyze_structure(b.bars, b.quote.price)   # 结构判定
votes = E.build_votes(b)                # 信号投票
html = rp.render(b)                     # HTML 报告
```

`Bundle` 主要字段：`quote`（行情）、`bars`（日K）、`weekly`（周K）、`tech`（技术指标）、`flows`（资金流）、`margins`（两融）、`chip`（筹码）、`consensus`（一致预期）、`score`（评分）、`profile`（简况）、`reports`、`news`、`errors`（数据缺口）。

## 可调整的阈值

集中定义在 `engines.build_votes()` 与 `report.py` 中，便于按风格调参：

- KDJ 超买线 90 / 超卖线 5
- 筹码获利盘偏空线 80%、偏多线 20%
- 放量 1.5 倍、缩量 0.7 倍
- 主力资金背离阈值 0.3 亿
- 融资余额变动阈值 2%
- 双底/双顶两脚偏离上限 6%、确认窗口 3 根 K 线
- 投票明确判定倍数 1.8
