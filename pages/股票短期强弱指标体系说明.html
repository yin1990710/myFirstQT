股票短期强弱指标体系（SSS, Short-term Strength Score）

五维评分模型 · 2026-09-16 · 与 W23 模型互补
定位：回答「这只股票当下 5–20 个交易日买/卖力量谁占优，未来 1–4 周是否更可能跑赢市场」。
与 W23 的关系：W23 抓「形态」（2 浪末/3 浪初的中期波段），SSS 抓「当下强度」。两者互为校验——W23 信号出现时，SSS 可作为入场排序权重；SSS 高分但 W23 无信号，往往是追高风险区。

1. RPS 相对强弱比率（权重 30%）

回答：过去 N 个交易日，个股相对基准是更强还是更弱？

要素定义
公式RPS = 个股 N 日涨跌幅 − 沪深 300 N 日涨跌幅
默认参数N = 20 日（可调 5/10/20/60；A 股市场 20 日是短期/中期分界）
标准化单标的：−10% ~ +10% 线性映射到 0–100；批量扫描：横截面百分位排名
解读分位 > 80% = 明显强；< 20% = 明显弱

为何权重最高：相对收益是短期强弱最直接的体现，且有大量 A 股实证支持。但它只看结果、不看原因，所以必须有其他指标补充验证。

2. VPVR 量价共振度（权重 20%）

回答：上涨时是否被资金确认？下跌时是否放量？

要素定义
公式VPVR = log(过去 N 日「上涨日均量 / 下跌日均量」)
分档0.5→10 分、1.0→50 分、2.0→80 分、3.0+→95 分
解读>1.5 量价齐升 = 真强；<0.7 上涨缩量 = 假强；放量下跌 = 真弱

为何用 log：线性量比会让极端值（一字板放量）主导分数；log 化后 0.5→3.0 的范围映射 10–95 分，符合视觉直觉。

3. TREND 趋势动量（权重 20%）

回答：形态是否处于多头排列？趋势强度够不够？

子项权重定义
MA5 斜率年化30%最近 5 日 MA5 变化率年化 → −20% ~ +60% 映射 0–100
价格站位40%收盘 > MA5 / MA10 / MA20 各占 1/3 权重
ADX30%14 日 ADX → 15–25 映射 0–100（25+ 视为强趋势）

与 RPS 的区别：RPS 看收益结果，TREND 看形态结构——即使 RPS 不高，只要 TREND 接近 60，说明已开始多头排列，是潜在转强信号。

4. MSR 动量夏普（权重 15%）

回答：上涨是「稳定走高」还是「脉冲暴涨」？

要素定义
公式MSR = (N 日累计收益 − 无风险) / N 日收益年化波动率
标准化横截面百分位；单标的用 −1 ~ +2 线性映射
解读MSR > 1.5 = 高质量强势；< 0 = 风险调整后为负

关键作用：排除「一日涨停 + 九日横盘」这种 RPS 看着不错但实际不稳的标的。一根大阳线冲高、随后缩量震荡的票，RPS 高、MSR 低——这是 SSS 必须识别的「假强势」。

5. MFI 主力资金净流入强度（权重 15%）

回答：有没有「聪明钱」在背后推动？

要素定义
公式MFI = 5 日 Σ(收盘−开盘)×成交量 ÷ 5 日 Σ 成交额
阈值−2% ~ +2% 映射 0–100
数据源升级粗口径可对接 AkShare stock_individual_fund_flow_rank 获取真实主力净额

背离信号（最有价值的部分）：当 RPS 高但 MFI 低 = 假突破风险；当 MFI 高但 RPS 低 = 资金抢筹但价格未启动，可左侧关注。

二、综合打分与等级

综合分 = Σ(指标分 × 权重) ÷ Σ(有效权重) # 缺数据指标权重自动归零
综合分区间等级操作建议
≥ 80强势 ★★★★W23 入场候选的优先标的；可单独建仓
65 ~ 80偏强 ★★★W23 信号出现时优先排序
50 ~ 65中性 ★★观察池；等待 W23 或量价共振确认
35 ~ 50偏弱 ★规避/减仓
< 35弱势不参与

缺数据时的优雅降级

任何指标取数失败时，权重自动按可用指标归一化（仍可合成总分）。这一指标对免费源场景至关重要——比如北向资金自 2024-08 后不再披露，MFI 缺数时仍能算出 4 维总分。

三、4 种「危险背离」必须主动识别

背离类型判读条件含义
量价背离RPS − MFI > 30涨幅领先但资金净流出——警惕假突破

动量断裂综合分 5 日内从 70+ 跌至 40 以下趋势可能已反转，立即止损/止盈

四、与 W23 协同使用的 3 种工作流

工作流 A：W23 信号确认（推荐主流程）

  1. W23 跑出 70+ 分候选池（含 2 浪末/3 浪初形态）
  2. 用 SSS 给候选池标的打分排序：综合分 ≥ 65 的优先建仓
  3. SSS < 50 的 W23 信号暂缓（形态对了但力量不足）

工作流 B：SSS 主动选股（捕捉非形态机会）

  1. 全市场扫描 SSS Top 30 → 这些是当下「真正强势」股
  2. 叠加 W23：得分双高 = 高置信度；仅 SSS 高 = 趋势已走出来（追高风险）；仅 W23 高 = 形态刚成形（可能是更好入场点）

工作流 C：动态仓位（SSS × MRI 联动）

  1. MRI 大盘风险指数决定仓位上限（如 MRI < 30 时可满仓，> 60 降至半仓）
  2. SSS Top 30 中 SSS > 80 的高强度标的优先分配资金
  3. SSS < 50 的标的即使 MRI 低也不轻易介入（个股强弱与大盘风险独立）

六、权重敏感性分析（避免过拟合）

5 项指标按信息含量独立性强、相互低相关（< 0.4），任意权重调整 ±5pp 综合分变化通常 < 8 分。但以下极端情况要主动避免：

不建议的组合原因
RPS > 40%会陷入「追涨陷阱」——只用过去收益预测未来
MFI > 25%资金面在 A 股阶段性失效（机构调仓、北向停披露）
MSR < 10%忽略波动率会让脉冲暴涨股反复入选

权重建议通过 Walk-forward 在 3 年滚动窗口上重训，而非一次性调死。配套 bt_engine.py 支持快速做这一验证。

七、失效条件与局限

必须明确标注的失效场景：
  • 小盘股（市值 < 30 亿）：流动性差，单日异常成交可拉高 VPVR，权重建议 VPVR < 15%
  • ST/*ST：5% 涨跌停使 MSR、TREND 失真，建议直接排除
  • 新股（上市 < 60 日）：无足够历史窗口计算，全部指标 NaN
  • 停牌/复牌日：单日涨跌常 > 20%，需在脚本里剔除（已实现）
  • 大盘崩盘期：SSS 高分股次日仍可能跌停——需 MRI 联动作为仓位上限
  • 北向资金停披露后：MFI 粗口径可能与真实主力行为偏差较大，建议接入 AkShare 主力净流入接口

八、运行示例

1. 单标的诊断

python short_strength.py --code 688213 --name 思特威

实测（2026-09-16）：思特威综合分 49.6（偏弱 ★）——RPS 67.5 收益仍可，但 TREND 44.3 + MSR 29.8 显示已现疲态，建议等待 W23 信号或 SSS 重新走高。

2. 全市场 Top30

python short_strength.py --top 30

输出 sss_top30.csv，可作为观察池与 W23 交叉验证。

3. 离线自检

python short_strength.py --selftest
