市场风险监测 · 方法论框架

A 股大盘风险评估指标体系

六维度全景框架：估值 · 情绪 · 资金流动性 · 技术 · 宏观基本面 · 市场结构
报告日期：2026 年 9 月 15 日 ｜ 性质：指标方法论梳理（阈值均为历史经验参考值，非实时数据）
配套工具：report_market_risk_index.py（六维 21 指标自动打分脚本）｜ A股大盘风险指数MRI.html（实测输出示例）
一句话结论：单一指标无法判断大盘风险，有效的做法是构建「估值定空间 + 情绪定热度 + 资金定流动性 + 技术定位置 + 宏观定周期 + 结构定拥挤」的六维监测体系， 将 20 个左右指标标准化为 0–100 分风险指数。高风险的典型共振组合是：估值分位 >80% + 融资余额占流通市值比创阶段新高 + 基金仓位 >88% + 指数远离年线 >30% + 成交额天量滞涨。

一、估值维度：决定"下跌空间"（慢变量、长周期锚）

估值是最可靠的左侧风险刻度，不预测何时跌，但决定跌下去有多少缓冲。

二、情绪维度：决定"过热程度"（快变量、反向指标集中营）

情绪类指标多为反向指标——市场越亢奋，风险越大。这是判断短期顶部最灵敏的一组。

指标风险读法（经验阈值）数据来源频率属性
融资余额 / 流通市值占比 >2.5%（历史高位阈值约 2.5%–3%）需警惕；2015 年 6 月峰值约 4.7%沪深交易所日领先
融资买入额 / 成交额>11%–12% 属杠杆过热（2015 年 6 月约 19%）交易所日领先
全A 换手率（或自由流通市值换手）周均换手率创 1 年新高并持续 3 周以上 = 过热Wind / AkShare日领先

涨跌停家数比、连板高度、封板率涨停 >100 家且连板高度 >5 板 = 投机过热；跌停潮 = 恐慌行情终端 / AkShare日同步

新增开户数 / 搜索热度开户数脉冲式增长、股票关键词搜索指数创新高 = 散户入场尾声中国结算 / 百度指数周领先

IPO / 再融资节奏发行节奏显著加快、超募频现 = 监管态度转松、抽血加剧证监会 / 交易所月领先

两融平均维持担保比例接近 130% 平仓线 = 强平踩踏风险交易所日同步

四、技术维度：决定"当前处在什么位置"

指标风险读法（经验阈值）数据来源频率属性
指数与年线（MA250）关系跌破年线并无法快速收回 = 趋势转熊的最强确认行情数据日同步
年线偏离度（BIAS250）>+30% 严重超买（2015 年 6 月、2007 年 10 月均 >40%）；<-20% 超跌行情数据日领先
均线排列与死叉MA20 下穿 MA60、MA60 下穿 MA120 = 中期趋势破坏的层级递进行情数据日同步
顶背离（价新高 + MACD/RSI 不新高）日线级别背离 = 短期警报；周线/月线背离 = 中期级别风险行情数据日/周领先
长周期动量（月线 RSI、周线 MACD 状态）月线 RSI >80 以上属历史极值区（A 股 30 年来仅数次）行情数据月领先
波动率（20 日 / 60 日年化）60 日年化波动率 <12% = 低波自满（后续常伴波动率放大）；>35% = 恐慌释放中行情数据日同步
市场宽度（腾落指标 ADL、新高新低差 NH-NL、上涨家数占比）指数新高但 ADL/上涨家数不配合 = 普涨结束、结构性风险；NH-NL 转负 = 内部走弱行情数据日领先
成交量价配合指数高位量价背离、突破日缩量 = 上攻动能衰竭行情数据日同步

五、宏观与基本面维度：决定"周期方向"

指标风险读法（经验阈值）数据来源频率属性
PMI（制造业/非制造业）连续 3 个月低于 50 = 经济下行确认；新订单-库存缺口转负为提前信号统计局月领先
全A（非金融）盈利增速与 ROE 趋势盈利增速由正转负、ROE 见顶回落 = 分母端支撑消失（戴维斯双杀风险）Wind / 财报季滞后
CPI / PPIPPI 深度负增长 = 工业通缩、企业利润承压；CPI 快速上行 = 政策收紧压力统计局月滞后
10 年期国债收益率收益率快速上行 = 流动性收紧/复苏预期（短期压制估值）；持续下行 = 避险或宽松中债日领先
人民币汇率（USDCNY）快速贬值（如 1 个月 >3%）通常伴随外资流出与风险偏好下降外汇交易中心日领先
美债 10Y / 美元指数 / 中美利差美债利率与美元指数快速上行 = 全球流动性收紧、新兴市场承压Wind日领先
政策变量（印花税、汇金增持、IPO 节奏、退市/减持新规）政策底通常领先市场底 1–2 个季度；收紧型政策（加税、限制交易）为直接风险证监会 / 国常会事件领先

六、市场结构与风险传导维度：决定"脆弱性有多高"

指标风险读法（经验阈值）数据来源频率属性
个股相关性 / 同涨同跌程度相关系数抬升 = 系统性风险主导（分散化失效），常伴随流动性冲击行情数据周同步
赛道拥挤度（如 TMT 成交额占比、前 5% 个股成交额占比）单一赛道成交占比 >40%–45% = 极度拥挤，均值回归风险大行情数据日领先
龙头集中度（前 10% 市值个股成交/涨幅贡献）"二八分化"极致 = 指数虚涨、赚钱效应差，回调时跌幅更大行情数据周领先
大小盘风格极致分化微盘股/小盘指数相对大盘的超额达历史极值（如 2024 年初、2015 年）→ 风格反转踩踏风险中证指数周领先
股指期货基差（IF/IC/IM 升贴水）贴水大幅走阔 = 对冲需求激增、机构悲观中金所日领先
期权 PCR（认沽/认购比）PCR 极端高（恐慌）常对应短期底部；极端低（乐观）对应顶部上交所/深交所日领先
信用利差 / 中资美元债利差走阔 = 信用风险上升，风险偏好收缩（股债联动风险）中债 / Bloomberg日领先
全球风险偏好（VIX、原油、黄金/比特币）VIX 跳升、避险资产大涨 = 外部冲击传染Wind日领先

八、如何合成为"大盘风险指数"

Step 1 标准化

所有指标统一转换为 0–100 的风险分位：对正向风险指标（如融资占比）直接用历史分位；对反向指标（如 ERP、破净率）取 100 - 分位。分位窗口建议 5 年（快变量）与 10 年（慢变量）并用。

Step 2 加权合成

方案 A：等权合成（推荐起步）

六维度各自内部等权，维度间等权。简单、不易过拟合，适合个人投资者。

方案 B：IC/ICIR 加权

用历史数据测算各指标对未来 3–6 个月指数收益的预测能力（信息系数），按 ICIR 加权。需至少 10 年样本。

方案 C：PCA 提取主成分

降维求第一主成分作为"系统性风险因子"，可解释 40%–60% 方差，但经济含义较难解读。

方案 D：分位数打分卡（实务首选）

每个指标按阈值给 0/1/2 分，加总后归一。透明、可回溯、便于人工干预。

Step 3 输出与使用

风险指数区间风险等级建议动作（示例）
0–30低风险（偏冷）可提高仓位，进攻性配置
30–50中性均衡持仓，做结构
50–70偏高降低仓位 / 提高对冲比例，收紧止损
70–100高风险（过热）显著减仓、保留现金、规避高拥挤赛道

九、使用注意事项（避免误用）

① 区分领先 / 同步 / 滞后：估值与宏观是慢变量，情绪与拥挤度是快变量。用慢变量择时会"太早"，用快变量择时会"太频繁"。建议：慢变量定仓位中枢，快变量做微调。
② 阈值会漂移：注册制、机构化、外资持股比例变化使历史阈值失效（如两融占比峰值已不可比）。所有阈值须用滚动窗口动态校准。
③ 警惕指标共线性：估值分位、ERP、PB 高度相关，等权合成时会隐性放大估值维度权重。建议维度内先合成再跨维度等权。
④ 反向指标不可单独使用：情绪指标能标出"过热区域"，但过热可以持续数月（如 2014Q4–2015Q5）。必须与趋势确认（跌破关键均线）结合才可执行。
⑤ "风险指数高"不等于"明天跌"：它衡量的是赔率恶化程度与潜在回撤深度，而非时点。定位为仓位管理工具而非择时工具。

十、可落地的数据源清单（免费 / 易获取优先）

  • 行情与估值：AkShare（PE/PB/成交额/均线/涨跌停家数）、中证指数官网、理杏仁、Wind（付费）
  • 两融与资金：沪深交易所官网（每日融资融券汇总）、AkShare 相关接口、沪深港通资金流
  • 宏观：国家统计局、央行官网、中国货币网（DR007/SHIBOR）、中债估值中心
  • 情绪与衍生品：上交所期权每日数据（IV、PCR）、中金所股指期货基差、中国结算开户数据
  • 基金：Wind / 中国基金业协会（月度发行份额、仓位测算）

脚本用法

  • python market_risk_index.py —— 自动取数并打印风险指数与明细（实测可覆盖 13/21 项）
  • python market_risk_index.py --init-manual —— 生成 8 项手工补数模板 mri_manual.json
  • python market_risk_index.py --input mri_manual.json --html out.html —— 手工值与自动值合并（手填优先）并输出 HTML 仪表盘
  • python market_risk_index.py --selftest —— 离线自检（过热/偏冷/缺数降级/合并优先级，共 4 项）
降级原则：取数失败的指标标记为 N/A，不按 0 分计入，合成指数按"有数据的维度"重新归一化权重。 理由：把缺失当作"低风险"会系统性低估风险。因此务必同时关注覆盖率（如 13/21），覆盖率过低时指数仅供参考。
本报告仅供研究参考，不构成个人投资建议。文中所有阈值均为历史经验参考值，随市场结构变化可能失效，使用前请以滚动窗口重新校准。
